## How to use
1. **Clone or download** this repository to your local machine.  
2. **Edit `index.html`** to update text, links, or images.  
3. **Replace images** in the `images/` folder with your screenshots (same filenames), or convert them to Base64 and embed directly in `index.html`.  
4. **Place the resume PDF** (`Senthil_Kumar_C_Resume_Final.pdf`) in the repo root so the download button works.  
5. **Test locally** by opening `index.html` in a browser.

---

## Deploy (GitHub Pages)
1. Create a GitHub repository (e.g., `senthil-portfolio`) and push your files to the `main` branch.  
2. In the repository, go to **Settings → Pages**.  
3. Under **Build and deployment**, choose **Deploy from a branch**. Select `main` and `/root`. Save.  
4. Visit the provided URL (usually `https://<username>.github.io/senthil-portfolio`) after a few minutes.

---

## Deploy (Netlify)
1. Sign in to Netlify and choose **New site from Git** or use drag‑and‑drop.  
2. Connect your GitHub repo or upload a zipped folder containing `index.html` and assets.  
3. Netlify will provide a free subdomain (you can add a custom domain later).

## Customization tips
- **Branding:** Update colors, fonts, and header image to match your personal brand.  
- **Projects:** Replace placeholder images with screenshots of RDLC reports, SSIS packages, or Power BI dashboards. Add case studies under each project.  
- **Analytics:** Add Google Analytics or Plausible for visitor tracking.  
- **Contact form:** Replace `mailto:` with a server endpoint or form service (Formspree, Netlify Forms) for better UX.  
- **Performance:** Keep images optimized; prefer separate image files for caching unless you need a single-file HTML.
